# 까만 막대

사진 속 **사람과 화면을 까만 막대로 가리고**, 사진에 숨은 **위치정보(EXIF)를 지우는** 웹 앱입니다.

- **사진이 기기 밖으로 나가지 않습니다.** 모델이 브라우저 안에서 돌아갑니다(ONNX Runtime Web, WebAssembly). 서버로 보내는 요청은 앱 파일과 모델을 받을 때뿐입니다.
- **가입이 필요 없습니다.**
- **PWA:** 홈 화면에 추가할 수 있고, 한 번 연 뒤에는 인터넷 없이도 동작합니다.

## 왜 블러가 아니라 까만 막대인가

블러나 모자이크는 원래 픽셀을 섞어 둔 것이라 AI로 일부 되살릴 수 있습니다. 까만 막대는 그 자리의 픽셀을 덮어써서 원래 정보가 남지 않습니다.

## 동작

1. 사진을 고르면 원본 크기로 다시 그립니다(EXIF 방향 반영, 최대 4096px).
2. 640×640으로 줄여 YOLO26n이 사람(COCO `person`)과 화면(`tv`, `laptop`, `cell phone`)을 찾습니다.
3. 사람은 '머리 쪽'(상자 위쪽) 또는 '몸 전체'를 가립니다. 화면은 상자 전체를 가립니다.
4. 막대를 누르면 켜고 끄고, 빈 곳을 끌면 막대를 새로 그립니다.
5. 저장하면 새 캔버스에서 JPEG로 만듭니다. 그래서 EXIF(위치·기기·시간)가 들어가지 않습니다.

## 기본값을 정한 이유

| 값 | 기본 | 이유 |
|---|---|---|
| 민감도(점수 임계값) | 0.20 | 개인정보는 **놓치는 쪽이 더 큰 손해**라 낮게 둡니다. 잘못 가린 막대는 눌러서 끄면 됩니다 |
| 사람 범위 | 머리 쪽 | 얼굴을 가리면서 사진은 남깁니다. 빗나가면 '몸 전체'로 바꿉니다 |
| 사람 판정 | 다른 클래스 점수가 더 높아도 사람 후보면 유지 | 같은 이유(놓치지 않기). 화면 클래스는 가장 높은 점수일 때만 씁니다 |

## 확인한 것

| 확인 | 결과 |
|---|---|
| ONNX와 PyTorch 결과 비교 (`bus.jpg`) | 같은 사람 4명과 버스를 찾음. 왼쪽 가장자리 사람 점수는 0.654 → 0.53으로 낮아짐(입력을 640×640 정사각형으로 채우는 방식 차이). 기본 민감도 0.20에서는 그대로 가려짐 |
| 브라우저 추론 시간 | 약 0.2초 (데스크톱, 단일 스레드 WASM) |
| EXIF 삭제 | GPS·카메라 정보·회전 값을 넣은 시험 사진 → 저장본에 `Exif`·카메라 이름 없음. 회전 값은 반영되어 똑바로 저장 |
| 오프라인 | 로컬 서버를 끈 상태에서 새로고침 → 모델 로드와 추론 정상 |
| 휴대폰 폭 (375px) | 가로 스크롤 없음, 공유 버튼 표시 |

## 못 하는 것 (꼭 직접 확인)

- **얼굴 위치를 따로 찾지 않습니다.** '머리 쪽'은 사람 상자에서 계산한 어림값입니다. 누워 있거나 잘린 사람은 빗나갈 수 있습니다.
- **번호판, 택배 송장, 이름표, 화면 속 글자**는 찾지 못합니다. COCO 80종에 없기 때문입니다.
- **사람을 놓치는 비율(재현율)은 아직 재지 않았습니다.** 정답 라벨이 있는 사진 묶음으로 재야 합니다.
- HEIC 사진은 브라우저가 열 수 있을 때만 됩니다(Safari는 가능, 일부 Chrome은 불가).

## 실행

정적 파일뿐이라 아무 정적 서버로 열면 됩니다. 서비스 워커 때문에 `file://`가 아니라 `http://localhost`로 열어야 합니다.

```bash
python3 -m http.server 8765
```

브라우저에서 `http://localhost:8765`를 엽니다.

## 파일

| 경로 | 내용 |
|---|---|
| `index.html`, `app.js` | 화면과 동작 (빌드 없음) |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA (오프라인 캐시, 홈 화면 추가) |
| `model/yolo26n.onnx` | `yolo export model=yolo26n.pt format=onnx imgsz=640` (ultralytics 8.4.208) |
| `vendor/ort/` | onnxruntime-web 1.20.1 (MIT). CDN 대신 직접 포함해서 외부 요청이 없음 |
| `samples/` | `bus.jpg` (Ultralytics 예제, AGPL-3.0), `laptop-desk.jpg` (Wikimedia Commons, CC0) |
